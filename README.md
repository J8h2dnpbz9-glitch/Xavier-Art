# Xavier Cáceres — sitio web

Sitio estático publicado con GitHub Pages. No requiere compilación ni dependencias.

## Estructura

- `index.html`, `en.html`: portadas en español e inglés.
- `shop.html`, `paintings.html`, `drawings.html`, `sculptures.html`: catálogo.
- `work1.html` a `work4.html`: fichas de obra.
- `archive.html`, `studio-notes.html`: archivo y cuaderno.
- `images/`: imágenes ya publicadas.
- `icons/`: iconos y favicons.
- `style.css`, `script.js`: estilos y comportamiento compartido.
- `xavier/`: rutas históricas que se mantienen porque el selector de idioma aún las utiliza.

## Publicar una modificación

Los cambios en `main` se publican automáticamente con GitHub Pages. Las imágenes nuevas deben optimizarse antes de incorporarse y utilizar formato JPEG o WebP cuando sea posible.

## Convenciones

- Mantener los nombres de imágenes en minúsculas y con guiones.
- No añadir archivos de sistema ni material de trabajo sin publicar.
- Conservar `width` y `height` en las imágenes para evitar saltos de diseño.
